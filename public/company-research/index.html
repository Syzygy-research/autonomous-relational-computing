Capability versus consequence

A capable system can generate plans, tool calls, payments, deployments, robot missions, access changes, or organizational commitments. That is the living map: a space of possible futures.

But a map is not a permission slip. VALIS-KORE sits at the consequence boundary and asks whether a proposed future has a legitimate path from the settled present into the world.

Canonical technical spine

CR → CE → RRS → ARC → VALIS-KORE

CR: computational object→CE: representation→RRS: computation→ARC: architecture→VALIS-KORE: reference implementation

This page mirrors the canonical repo language: Consequential Reachability is the object, the Consequence Envelope represents a proposed transition, Recursive Relational Settlement computes the boundary, the Autonomous Relational Computer is the architecture, and VALIS-KORE is the reference implementation and company building the production path.

Concrete example: autonomous payment

An agent may propose paying a vendor. VALIS-KORE does not ask only whether the agent can call a payments API. It asks whether this exact amount, counterparty, account, participant, policy, exposure limit, time window, and evidence requirement are legitimately reachable. If any material value changes, the previous release no longer applies.

Evidence posture

Strong evidence, bounded claims

VALIS-KORE is an executable and falsifiable reference implementation path. The Phase V comparator baseline executed 35/35 across seven scored axes, and the repository-local reference closure campaign is ready to freeze. Bounded reference evidence is still not production-kernel conformance, external validation, or universal proof.

Risk / insurance program

Autonomous systems create a new underwriting problem

Traditional controls can establish identity, permissions, transactions, logs, and monitoring. Autonomous systems can generate interacting consequential transitions at machine speed under changing state and incomplete knowledge of external effects.

Consequential Reachability creates a computational substrate: what consequential states remain legitimately reachable, what was released, what effect was observed, what uncertainty remains, and what evidence survives afterward.
