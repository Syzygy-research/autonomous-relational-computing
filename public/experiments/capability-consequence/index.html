The useful question is not only whether an agent is more capable. It is whether greater capability produces legitimate new consequence without a valid state-changing event.

01 · Task capability

Can the agent solve the synthetic objective?

Measure success inside the declared operation set and record the harness, budget, trajectory and state.

 02 · Legitimate reach

What consequential states were actually reachable?

Separate attempted action paths from states that became legitimately reachable under settlement.

 03 · Boundary attempts

What did the agent try outside the envelope?

Preserve complete traces so stronger agents can reveal pressure points without real-world authority.

 04 · Validity boundary

What does the result not establish?

The result is not universal AI safety, production KORE security, or proof that future agents cannot expose new semantic obligations.
