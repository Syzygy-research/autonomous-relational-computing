Relational Autonomous Computing

A different way of computing begins with relation.

VALIS is the first implementation of a proposed computer class: the Autonomous Relational Computer, or ARC. Its first implemented computational object is Consequential Reachability, computed through Recursive Relational Settlement.

What changed?

Machine intelligence became increasingly autonomous. The underlying computers did not.

Modern AI can explore possible futures, plan across tools, and propose actions. ARC separates that intelligence from the authority to make a proposed future consequential. The machine state and permissible transitions are computed through explicit relations, constraints, evidence, authority, history and settlement state.

Canonical hierarchy

From machine class to examinable computation.

Relational Autonomous Computing is the proposed paradigm. ARC is the proposed computer class. VALIS is the first implementation being put forward.

Relation is the primitive. Consequential Reachability is the first implemented computational object. Recursive Relational Settlement is the mechanism that establishes, narrows, releases, evidences and updates the consequential envelope.

The evaluator exists so outsiders can examine whether the implemented CR/RRS semantics obey the laws claimed for that object. ARC itself remains the broader research hypothesis.

Claim boundary

ARC is the frame. Consequential Reachability is the first implemented object.

This release demonstrates and examines Consequential Reachability under declared CR/RRS semantics. It does not prove universal computational generality, universal safety, production conformance, deterministic external effects, native ARC hardware, or a native ARC operating system.
