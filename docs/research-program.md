# ARC research program

ARC-0 -- A Calculus of Relational Autonomous Computation is the next formal research target. It is not completed by this release.

The research program begins from relation as primitive rather than from an AI-governance product category. It investigates the minimal formal machine that can compute over relational configuration space.

Research questions include minimal relational primitives, transition operators, settlement semantics, recursion, reachability, closure, admissibility, boundary computation, path computation, stability, provenance, evidence semantics, distributed relational state, compositionality, computational expressiveness, reduction against established models of computation, and domain generalization.

Consequential Reachability is Computational Object 01. Future objects should be derived systematically from the formal architecture rather than added as branding concepts.
