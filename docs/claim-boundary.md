# Claim boundary

Public claims use four top-level classes.

- IMPLEMENTED: executable material exists in this release.
- DEMONSTRATED: supported by current evaluator, conformance, or test evidence.
- FORMALIZED -- BOUNDED: supported only within stated formal assumptions and scope.
- RESEARCH: motivated by the architecture but not established by this release.

This release does not claim universal computational generality, universal safety, deterministic external-world effects, perfect observability, production KORE conformance, native ARC hardware, or a native ARC operating system.
