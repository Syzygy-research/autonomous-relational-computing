What may a machine legitimately make real?

Autonomous systems increasingly move from producing information to initiating external consequence. VALIS-KORE is a Autonomous Relational Computer architecture built around one continuously changing question: given the relationships, authority, constraints, exposure, evidence, and prior effects that exist now, what consequences are legitimately reachable now?

Intelligence generates possible futures. VALIS represents those futures as proposed consequential states. The power to imagine a future is not, by itself, the authority to make that future real.

Orientation · Programmable Consequence

A decision is not a consequence.

A machine can compute that something should happen. A consequence is a change in the world. VALIS makes the boundary between those two states explicit and computable.

PROGRAMMABLE CONSEQUENCE

The public concept: software can explicitly represent and enforce the boundary governing which proposed real-world changes may proceed.

CONSEQUENCE BOUNDARY

The architectural boundary between computation and real-world consequence.

CONSEQUENTIAL REACH

The scope of consequence available under settled authority, constraints, state and exposure.

CONSEQUENTIAL REACHABILITY (CR)

The formal property: whether a proposed consequential state is reachable from the currently settled state.

The boundary that matters

VALIS moves determinism to the transition from computation to consequence.

The intelligence does not need to become deterministic. The external world does not need to become perfectly observable. The consequence boundary can still preserve deterministic invariants governing which proposed transitions may legitimately proceed.

The machine economy

A machine economy requires more than programmable intelligence. It requires programmable consequence.

As machine judgment becomes cheaper, faster and more abundant, consequential reach becomes a resource that must be allocated, bounded, settled and accounted for.

Programmable intelligence

Generate judgments, plans, predictions, proposals and possible futures at machine speed.

Programmable consequence

Keep consequential reach independently bounded by settled authority, constraints, exposure, state and evidence.

We do not have to solve trust in intelligence before we can bound the consequences of intelligence.

05 · Failure is evidence

Known counterexamples stay in the record.

FC-CE-001A proof-model typing defect was found during foundational work, corrected, and affected work rerun. The correction strengthens the evidence record only if the original failure remains visible.
Authority separation incidentA historical GMAP/Astra path allowed agent-accessible approval behavior to cross a boundary intended to require independent human semantic control. The incident is a P0 historical counterexample for production authority separation, not something to erase after correction.
Effect truth riskSource review identified the possibility that execution could precede receipt submission and that a generic failure receipt could misrepresent whether mutation occurred. Production failure injection is therefore a separate high-priority obligation.
Restart / recoveryEarlier live evidence showed downstream governed reads held outside admission release. Current state must be retested rather than assumed from historical evidence.
Implementation agreement is not semantic correctness. Semantic correctness is not deployment correctness. Deployment correctness is not complete mediation. A receipt is not the world.
06 · Research program

Try to reduce it. Try to break it. Try to reproduce it.

Strongest comparator

The comparator is deliberately allowed to compose supervisory control, UCON-style ongoing authorization, capability tokens, exposure ledgers, workflow/dependency state, runtime effect monitoring, attestation/evidence, and relational principal state.

Novelty boundary

Formal irreducibility is not established. If ordinary constructs reproduce the semantics cleanly, accept that result. If reproduction requires an integrated cross-component state substantially equivalent to Consequential Reachability, that is architectural evidence—not automatically a theorem.
