# Invariants

The public evaluator and evidence artifacts expose invariants around authority provenance, exact binding, proposal versus release separation, replay resistance, one-time execution, expiry, revocation, cumulative exposure, anti-sharding, restart non-widening, delegation, stale state, causal ordering, effect uncertainty, evidence correction/finality, and receipt/evidence boundaries where supported by public artifacts.

The evidence registry identifies what is implemented, demonstrated, formalized within a bounded proof, or still research.
