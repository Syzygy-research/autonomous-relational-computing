# Architecture

The public stack for this release is:

| Layer | Canonical term |
| --- | --- |
| Computing paradigm | Relational Autonomous Computing |
| Computer class | Autonomous Relational Computer (ARC) |
| First implementation | VALIS |
| Kernel | VALIS-KORE / CR-Core |
| Primitive | Relation |
| First computational object | Consequential Reachability |
| Core mechanism | Recursive Relational Settlement |
| Boundary representation | Consequential Envelope |
| Test specification | Semantics, invariants, executable vectors |
| External examination | Evaluator |
| Integration surface | Gateway / infrastructure layer |

ARC separates intelligence that explores possible futures from computational authority that determines which consequential transitions are reachable.
