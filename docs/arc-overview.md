# ARC overview

Relational Autonomous Computing begins from relation as a computational primitive. Conventional systems can represent relationships; ARC makes the stronger architectural move that relations participate directly in determining computational state and permissible state transition.

The lineage is primitive -> ontology -> epistemology -> computation -> mechanism -> object -> application. Relation as primitive leads to relational state, identity, boundary, evidence, history, authority, composition and recursion. Recursive Relational Settlement is the mechanism that operationalizes changes in relational configuration.

VALIS is the first implementation being put forward. Its first implemented computational object is Consequential Reachability: determining which consequential states are legitimately reachable from the current relational configuration.

Autonomous machine intelligence is an application/problem domain for ARC. It is not the definition of ARC. Consequential Reachability addresses a central problem created by autonomous machine intelligence: separating what intelligence can propose from what a machine can legitimately make consequentially reachable.

ARC itself remains the research hypothesis that gets tested next. This release demonstrates and examines CR/RRS as the first implemented object; it does not prove the ultimate generality of ARC.
