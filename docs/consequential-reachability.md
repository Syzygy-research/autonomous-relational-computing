# Consequential Reachability

Consequential Reachability is the first implemented computational object in the public ARC / VALIS release.

It asks which consequential states or transitions are reachable from the current relational configuration under applicable identity, authority, constraints, budgets, exposure, history, settlement, and evidence state.

Possible, reachable, settled, released, executed, and observed effect are separate states. UNKNOWN evidence never silently becomes success.
