# Security and disclosure

## Reporting a vulnerability

If you find a security issue in this package or in the evaluator
artifacts it publishes, report it privately before disclosing it
publicly:

**info@recursive-settlement.com**

Please include:

- the artifact and the version or commit you tested,
- a minimal reproduction or proof of concept, and
- the impact you believe it has, stated at the strength you verified.

## What to expect

- Acknowledgement of your report.
- Coordinated disclosure: a fix and a public note are agreed with you
  on a shared timeline before either side publishes details.
- Credit in the fix's release record, if you want it.

## Scope

This package is a public examination package: local, offline testing
is the intended route, and reports from local testing are exactly what
this address is for. Please do not test against live systems you do
not own or have permission to test.
